# Landing artwork

Created with the built-in imagegen tool using the supplied Sky Studio screenshot
as the composition/style reference. `miso-reading.png` also used the existing
`src/assets/miso/hero.png` as a character reference. All final PNGs retain their
generated transparency; originals remain in the Codex generated-images folder.

The existing avatar sprite is reused directly by the landing page. A blue book
stack was generated after inspecting the existing green/purple books sprite.
Clouds, icons, window frames, and layout are real HTML/CSS/SVG.

## miso-reading.png — final prompt

Create one isolated transparent PNG sprite for Miso's landing page. Reference
image 1 is the landing-page composition: replicate as closely as possible ONLY
the little white fluffy cat reading a blue book in the lower right, not the rest
of the page. Reference 2 is the existing Miso character identity. White/ivory
fluffy cat, warm gray brown ears and tail, bright blue eyes just over an open
dark blue book with a tiny pale cat-head emblem. Cat sits to the right behind
the book, little front paw visible, curled tail right. The book is to the lower
left of the body, cat looking at reader over book. Crisp charming pixel art,
small visible square pixels, restrained cream/blue/brown palette with dark brown
outlines. Match reference 1 pose and simple proportions, not realistic fluffy
rendering. Whole character and book fully within frame with minimal transparent
padding, no text, no ground, no shadow outside silhouette, no UI, no other props.
Intended displayed size approximately 175px wide by 150px high. Truly transparent
background.

## flowers.png — final prompt

Generate one isolated decorative pixel art sprite on truly transparent background:
the tall slender potted plant from the lower LEFT of this reference landing page.
Only the plant, not the books, UI or background. Cream ceramic flowerpot with
pale tan horizontal stripes, slender branching dusty dark teal stems and small
square dark teal leaves, a few little ivory white blossoms with pale gold centers.
Whole plant, tall narrow shape around 100 wide by 180 high display pixels. Match
the reference precisely in palette, silhouette, crisp retro square pixels and
charming restrained shading. No ground, shadow outside sprite, no backdrop,
no text, no additional objects. Minimal transparent padding.

## books.png — final prompt

Create one isolated pixel art sprite with genuinely transparent background. Only
a stack of THREE horizontal textbooks, matching the lower-left book stack in the
provided landing-page reference. Low wide stack, width about 110 display pixels
by 90 high: bottom thick dark muted navy-blue covered textbook with cream page
edges, middle ivory cream textbook with subtle tan page lines and a blue spine
accent, top thinner blue hardback. Uneven protruding edges, square stepped pixel
silhouettes. Crisp visible pixel art with subtle restrained shading and warm ivory
pages. Dark muted blue covers, NOT cyan, purple or green. Straight-on slight
top-down view as in the reference. No text, no logos, no cat, no plant, no floor,
no background, no added shadows outside the silhouette. Minimal transparent
padding. This is a reusable decoration sprite for a sky blue and cream study
website.
